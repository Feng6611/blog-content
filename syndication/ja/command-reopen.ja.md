## 背景

Macは乗り換えのハードルこそ高いものの、一度慣れてしまうともう手放せなくなるデバイスです。2020年に大学を卒業して初めてMacを手にしたときは、わざわざ『白皮書』（Mac初心者向けガイド）を読み込み、YouTubeの講座を見漁り、先輩に手取り足取り教わりながら「3本指ドラッグ」や「4本指でのデスクトップ切り替え」を設定して、ようやく少しずつ扱えるようになりました。
macOSには独自の設計思想がありますが、それが洗練されたこだわりなのか、ただの頑固さなのか判断に迷うことがあります。他のOSの操作感が体に染みついていると、どうしても手になじまない挙動がいくつか出てくるものです。

たとえば、`Cmd+W`でウィンドウを閉じたり、`Cmd+M`で最小化したりした際、システム側は次のように処理します。
- アプリ自体は終了（Quit）しておらず、`Cmd+Tab`のアプリスイッチャーにはまだそのアプリが残っている
- しかしウィンドウはすでに閉じているか最小化されているため、`Cmd+Tab`でそのアプリに切り替えてもウィンドウは再表示されない（開かない）

この問題をどうにか解決できないかと調べてみたところ、だいたい次の3つの対処法が見つかりました。
- 閉じる・最小化する代わりに`Cmd+H`で非表示にする。非表示にしたアプリなら`Cmd+Tab`でウィンドウを復帰できる（とはいえ、自分の操作習慣にはまったく合わない）
- `Cmd+Tab`でアプリを選択した状態で`Option`を押し続け、そのあと`Cmd`を離すとウィンドウが表示される（ただ、このキー操作に成功したためしが一度もない）
- Dockからクリックしてアクティブにする（……）

そんなわけで我慢の限界に達し、バイブコーディング（Vibe Coding）でこの問題を解決するアプリを作ることにしました。

## Command Reopenの実装

この仕様に散々悩まされていた頃、`Cmd+Tab`の挙動をじっくり観察してみました。すると、開いているウィンドウがないアプリに切り替えた場合でも、アプリ自体はきちんとフォアグラウンド（最前面）に持ってこられているのです。ただ単に、ウィンドウが開いていないだけでした。

そのため、Command Reopenのアプローチはいたってシンプルです。システム側のフォアグラウンドアプリ切り替えイベントを監視し、「アプリが最前面に来たのに可視ウィンドウが存在しない」ことを検知したら、すかさず再オープン（reopen）の命令を送ってウィンドウを呼び起こします。

世の中にある既存の解決策（[AltTab](https://alt-tab-macos.netlify.app/)に代表されるツールなど）は、ウィンドウのプレビューや並び替えといった複雑なウィンドウ管理機能を備えていることが多く、中にはネイティブの`Cmd+Tab`画面そのものを上書きして再描画するものまであります。しかも、そうしたツールの多くはアクセシビリティ権限や、場合によっては画面収録権限まで要求してきます。

Command Reopenは、まさにこのひとつの問題だけを解決するツールです。システムのUIを変更することも、複雑なロジックを挟むこともありません。ただ「ウィンドウをアクティブにする処理」をひとつ補正するだけ。ですが、私の普段使いにおいては、これで完全に十分でした。

## ゼロ権限ゆえの制約

システムに対するセンシティブな権限を一切要求しない方針を貫いているため、現在の実装には客観的な制約が2点あります。

### 1. ウィンドウ単位の制御ができない

ウィンドウ単位でのきめ細やかな管理を行うには、アクセシビリティ権限（AX権限）を要求する必要があります。そのため、現在のCommand Reopenができるのはアプリ単位での復帰にとどまります。たとえば、あるアプリに最小化されたウィンドウが複数ある場合、復帰できるのは一番上（最前面）のウィンドウだけであり、特定のウィンドウを指定してアクティブにすることはできません。

### 2. アプリがmacOS標準のウィンドウ仕様に準拠している必要がある

この仕組みは、対象となるアプリがmacOSのウィンドウAPIを標準的な作法で実装していることを前提としています。そうでないと、システムからのアクティブ化命令を正しく受け取れないからです。もしアプリ独自の「オレオレ実装（手作りの非標準な実装）」でウィンドウを管理している場合、うまく動作しない可能性があります。

実際のテスト環境でも、ユーザーからの報告で「飛書（Feishu / Lark）から起動した飛書会議がDockに単独のアイコンを占有するケース」が見つかりました。この場合、Command Reopenのアクティブ化処理にはまったく反応しませんでした。他にもまだ見つかっていない非標準なアプリが存在するかもしれません。

とはいえ、私が半年以上日常的に使っている限りでは、主流なアプリのほとんどは基本的に問題なく動いています。
